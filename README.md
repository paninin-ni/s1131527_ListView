### 視窗（二）圖書管理程式

### 專案簡介:
> 提供直觀且具互動性的介面供使用者瀏覽與管理經典圖書清單。系統完整呈現圖書的「書名」、「作者」及「類別」等核心資訊，並內建彈性的「檢視方式」切換功能，支援五種不同的視圖模式（如詳細資料、大圖示等）。具備借閱管理與防護機制，透過雙擊操作即可觸發借閱確認，並能自動攔截已存在清單中的重複書目，確保借閱紀錄的正確性。


### 執行說明:

> 1. 瀏覽書目：檢視左側的圖書清單，畫面初始化即會自動載入《三國演義》、《西遊記》等經典書籍的名稱、作者與類別資訊
> 2. 切換檢視方式：透過右方的「檢視方式」下拉選單，可自由切換 ListView 的呈現樣貌，系統支援「大圖示」、「詳細資料」、「小圖示」、「清單」及「大圖示加詳細資料」等五種無縫切換模式
> 3. 觸發借閱：針對欲借閱的書籍，直接在清單上雙擊（Activate）該圖書項目，系統將攔截操作並彈出「確定要借閱嗎?」的專屬確認視窗
> 4. 寫入清單：在提示視窗點擊「是 (Yes)」，程式會將該書名自動新增至專屬的借書清單（lstBorrow）中進行記錄
> 5. 重複防呆機制：系統會在每次借閱前進行比對，若雙擊「已經借閱過（已存在借書清單中）」的書籍，程式將自動略過，不會重複彈出詢問視窗或產生重複的借閱紀錄
